| 组件 | v16 要求 | Ubuntu 24.04 自带 |
|---|---|---|
| Python | 3.14（frappe pyproject: >=3.14,<3.15） | 3.12 |
| Node | >=24（frappe package.json engines） | 18.19 |
| MariaDB | 11.8 | 10.11 |
| Redis | 6+ | 7.0.15（达标） |
| Yarn | 1.22+ | 无 |
| pip | 25.3+ | 24.x |
